# Numoral Hanoi — สถิติหวยฮานอยปกติ (PWA)

แอปสถิติหวยฮานอยปกติ (ผลสลากภาคเหนือเวียดนาม XSMB) ที่ต่อยอดจาก Numoral VIP ใช้หน้าตาและสูตรชุดเดียวกัน
แอปนี้วิเคราะห์สถิติอย่างเดียว ไม่รับแทงและไม่รับเงินใดๆ · แยกขาดจาก Numora และ Numoral VIP (ไฟล์, repo, Worker, KV และข้อมูลในเครื่อง)

## มีอะไรบ้าง

| ไฟล์/โฟลเดอร์ | หน้าที่ |
|---|---|
| `index.html`, `app.js`, `vendor.js`, `styles.css` | ตัวแอป (`app.js` ฝังผลย้อนหลังไว้ 2,042 งวด: 12 มี.ค. 2564 – 18 พ.ย. 2569) |
| `manifest.json`, `sw.js`, `icons/` | ติดตั้งลงมือถือและเปิดออฟไลน์ได้ (ไอคอนมีป้าย HANOI สีแดง-เหลือง) |

## โมเดลข้อมูล

- **3 ตัวบน / 2 ตัวบน** = 3 / 2 หลักท้ายของ **รางวัลพิเศษ (Đặc biệt)** 5 หลัก
- **2 ตัวล่าง** = 2 ตัวท้ายของ **รางวัลที่ 1 (Giải nhất)** ซึ่งจับแยกจากรางวัลพิเศษ
- ออกทุกวันราว 18:15–18:30 น. (เวลาไทย) และหยุด 3–4 วันช่วงตรุษญวน
- ข้อมูลที่ขาด: ผลที่ raakaadee ไม่มี 16 งวด (5 งวดในปี 2564 และ 16–28 ก.พ. 2566 บางวัน) ไม่ได้เติมเอง เพราะต้องมีทั้งรางวัลพิเศษและรางวัลที่ 1

## ระบบดึงผลอัตโนมัติ

ตารางเวลา (เวลาไทย): 18:40, 18:55, 19:15, 19:45, 20:30 และสำรอง 08:10 น. ของวันถัดไป

**กติกาการบันทึกผล:** ดึงจาก raakaadee.com แล้วเทียบกับ RSS ผลสลากภาคเหนือของ xskt.com.vn
- ตรงกัน (ทั้งรางวัลพิเศษและ 2 ตัวท้ายรางวัลที่ 1) → บันทึก
- ไม่ตรงกัน → ไม่บันทึก รอรอบถัดไป
- มีแค่แหล่งเดียว → บันทึกเมื่ออีกแหล่งเปิดไม่ได้ หรือเป็นงวดของวันก่อนหน้า (รอบเช้าวันถัดไปจะบันทึกให้)

แถวจาก raakaadee ต้องผ่านการตรวจตัวเอง (เลขท้าย 3 ตัวและ 2 ตัวที่เว็บแสดงต้องตรงกับรางวัลพิเศษ) ไม่งั้นจะถูกทิ้ง

## อัปเดตแอปเวอร์ชันใหม่

แก้ไฟล์แล้วเปลี่ยน `const VERSION` ใน `sw.js` (เช่น `h1.0.0` → `h1.0.1`) แล้ว push

## ทดสอบตัวแยกข้อมูลในเครื่อง (ไม่ต้องต่อเน็ต)

```
node scripts/update-draws.mjs --test
```
